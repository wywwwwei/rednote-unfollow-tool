# Rednote / 小红书关注列表管理与批量取关助手

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Console%20%7C%20Bookmark%20%7C%20Extension%20%7C%20Tampermonkey-red.svg)](https://www.rednote.com)
[![Privacy](https://img.shields.io/badge/Privacy-100%25%20Local-green.svg)](#-安全与隐私承诺)

专为小红书 / Rednote 网页端设计的开源关注列表管理与批量取关工具。**纯前端运行、无需安装 Python 或本地后端服务**，直接在浏览器中复用原生会话与签名，零跨域、零网络中转。

---

## 🌟 核心功能

1. **⚡ 全量自动拉取**：自动分页拉取关注列表（单页 20 人，安全间隔 500ms），支持 1000+ 大量关注数据完整抓取，支持实时进度展示与随时中止。
2. **👑 互相关注置顶**：自动识别并置顶展示互关好友（绿色标识与皇冠标志），保护重要好友关系不被误触。
3. **⏱️ 单向关注按时间倒序**：非互关博主严格按照关注时间倒序排列（最近关注在最前，最早关注在最后），方便清理远期不活跃关注。
4. **🎯 仅勾选所有单向关注**：一键智能勾选所有非互关博主，自动排除互关好友，极大降低误操作风险。
5. **🛡️ 安全限流批量取关**：单项请求间隔 1.2 秒执行，规避平台频率风控与验证码拦截，带实时取关计数与状态反馈。
6. **💾 本地数据备份与日志**：支持一键导出全部关注列表备份（CSV），以及取关明细操作记录（CSV），防止误取关后找不到博主主页。

## 🚀 使用方式

本项目提供以下四种运行方式，操作步骤分别如下：

### 方式一：浏览器控制台运行

1. 在电脑浏览器中打开并登录 [小红书网页版](https://www.rednote.com/) 或 [xiaohongshu.com](https://www.xiaohongshu.com/)。
2. 打开开发者工具控制台：
   - **Windows 用户**：按键盘 `F12`（或右键点击页面任意位置 -> 选择【检查】-> 切换到【控制台 / Console】）。
   - **Mac 用户**：按快捷键 `Command + Option + I`（或右键【检查】->【Console】）。
3. 复制 [`userscript.js`](./userscript.js) 的全部代码。
4. 粘贴到控制台中并按回车键执行。
   > 若浏览器提示 `Warning: Don't paste code here` 并拦截粘贴，在控制台输入 `allow pasting` 后按回车即可解除限制。
5. 页面右下角将出现 **【⚡ 关注管理 & 批量取关】** 悬浮球，点击即可展开管理面板。

---

### 方式二：浏览器书签运行 (Bookmarklet)

1. 在浏览器书签栏空白处右键，点击【添加网页】或【添加书签】。
2. 名称填写：`小红书批量取关`。
3. 网址 (URL) 填写以下代码：
   ```javascript
   javascript:(function(){const s=document.createElement('script');s.src='https://cdn.jsdelivr.net/gh/wywwwwei/rednote-unfollow-tool@main/userscript.js?t='+Date.now();document.body.appendChild(s);})();
   ```
4. 保存后，在小红书网页端点击该书签即可载入面板。

---

### 方式三：Chrome / Edge 扩展程序

1. 下载项目仓库文件并解压到本地。
2. 打开浏览器扩展管理页面：
   - **Chrome**：访问 `chrome://extensions/`
   - **Edge**：访问 `edge://extensions/`
3. 开启页面中的【开发者模式】开关。
4. 点击【加载已解压的扩展程序】，选择项目中的 `extension` 目录。
5. 访问小红书网页端，页面右下角将自动加载悬浮球。

---

### 方式四：用户脚本 (Userscript / 油猴)

1. 打开浏览器已安装的脚本管理器（如 Tampermonkey、Violentmonkey 或脚本猫）。
2. 新建脚本，复制本项目中的 [`rednote-unfollow.user.js`](./rednote-unfollow.user.js) 全部内容并保存。
3. 访问小红书网页端即可自动加载。

## 📖 推荐操作流程

1. **打开面板**：点击网页右下角悬浮球，助手会自动识别当前登录账户的 UID（若未识别，输入主页 24 位 UID 即可）。
2. **一键拉取**：点击 **【⚡ 一键拉取全部】**，程序将自动循环翻页获取所有关注数据。
3. **备份列表**：数据加载完毕后，建议先点击底部 **【💾 备份关注列表 (CSV)】** 保存一份原始关注名单。
4. **智能勾选**：点击 **【🎯 仅勾选所有单向关注】**，自动全选非互关人员（互关好友受保护不被选中）。
5. **执行取关**：点击 **【批量取关所选】**，程序将以 1.2 秒安全间隔执行取关，避免触发验证码。
6. **保存记录**：取关完成后，可点击 **【📥 导出取关记录 (CSV)】** 存档操作明细。
